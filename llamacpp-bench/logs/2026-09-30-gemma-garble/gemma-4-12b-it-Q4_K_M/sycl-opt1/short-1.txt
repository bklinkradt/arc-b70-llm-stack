A hash map (or dictionary) works by using a **hash function** to turn a key (like a string or integer) into a specific index in an underlying array.

A **collision** occurs when two different keys produce the exact same index. Since an array slot can only hold one piece of data at a time, the hash map must have a strategy to store both.

There are two primary ways to handle this:

### 1. Separate Chaining (Most Common)
Instead of storing the value directly in the array slot, each slot holds a **linked list** (or another list). If multiple keys map to the same index, they are simply appended to that list.
*   **Pros:** Simple to implement; the map never "fills up" (it just gets slower).
*   **Cons:** If many keys collide at one index, performance drops from $O(1)$ to $O(n)$.

### 2. Open Addressing
If a collision occurs, the hash map looks for the **next available empty slot** in the array. Common methods include:
*   **Linear Probing:** Check the next slot ($index + 1, index + 2...$).
*   **Quadratic Probing:** Check slots at increasing intervals ($1^2, 2^2, 3^2...$).
*   **Double Hashing:** Use a second hash function to determine the step size.

---

### Python Example: Separate Chaining
Since Python's built-in `dict` is highly optimized (it actually uses a variation of open addressing), it is better to write a simple manual version to see how **Separate Chaining** works.

class SimpleHashMap:
    def __init__(self, size=10):
        self.size = size
        # Create an array of empty lists (Separate Chaining)
        self.table = [[] for _ in range(self.size)]

    def _hash(self, key):
        # A simple hash function: take the modulo of the key's hash
        return hash(key) % self.size

    def put(self, key, value):
        index = self._hash(key)
        # Check if key already exists in the list at this index
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value) # Update existing
                return
